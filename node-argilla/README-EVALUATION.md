# Chat Evaluation System for AnswerAI

This system allows you to evaluate the quality of AI chat conversations by creating an evaluation dataset in Argilla. You can assess different aspects of each conversation, including information quality, tool usage, response quality, and document relevance.

## Setup

1. Make sure you have an Argilla server running. If not, follow the [official Argilla installation guide](https://docs.argilla.io/en/latest/getting_started/installation.html)

2. Copy the example environment file and fill in your details:
   ```bash
   cp .env.example .env
   ```

3. Edit the `.env` file with your Argilla API URL, API key, and workspace information

## Creating and Populating the Evaluation Dataset

### Using JavaScript/Node.js

1. Make sure you have Node.js installed

2. Install dependencies:
   ```bash
   npm install
   ```

3. Create a test dataset with synthetic examples:
   ```bash
   node create-test-dataset.js
   ```

4. To load your own chat data:
   ```bash
   node load-chat-evaluation.js
   ```
   This will look for data in the `examples/answerai-chat-example.json` file by default.

### Using Python

1. Make sure you have Python 3.8+ installed with the Argilla package:
   ```bash
   pip install argilla
   ```

2. Create a test dataset with synthetic examples:
   ```bash
   python create-test-dataset-python.py
   ```

3. To load your own chat data, you can modify the `chat_evaluation_python.py` script to point to your data file

## Understanding the Dataset Structure

The evaluation dataset includes the following components:

### Fields (Data to Evaluate)

- **User Query**: The question asked by the user
- **AI Response**: The response generated by the AI
- **Agent Reasoning**: The reasoning process of the agent
- **Tools Used**: The tools used during the conversation
- **Source Documents**: Documents referenced during the conversation

### Questions (Evaluation Metrics)

- **Information Quality**: Rate the accuracy and relevance of the information provided (1-5)
- **Tool Usage Effectiveness**: Rate how effectively tools were used to answer the query (1-5)
- **Overall Response Quality**: Rate the overall quality and helpfulness of the response (1-5)
- **Document Relevance**: Rate the relevance of the referenced documents (1-5)
- **Improvement Suggestions**: Provide specific feedback on how the response could be improved

## Evaluating Conversations

1. Access your Argilla instance (e.g., http://localhost:6900)
2. Log in with your credentials
3. Navigate to your workspace
4. Open the "chat_evaluation" dataset
5. For each record:
   - Review the conversation details
   - Rate each aspect using the provided scales
   - Provide improvement suggestions if needed
   - Submit your evaluation

## Analyzing Results

After evaluating conversations, you can use Argilla's metrics view to analyze the overall performance of your AI system. The metrics can be filtered by metadata fields to help you understand performance trends.

For more advanced analysis, you can use the Argilla Python client to load the evaluated dataset and perform custom analysis:

```python
import argilla as rg

rg.init(
    api_url="your-argilla-api-url",
    api_key="your-api-key"
)

# Load the evaluated dataset
dataset = rg.FeedbackDataset.from_argilla("chat_evaluation", workspace="your-workspace")

# Process the evaluations
for record in dataset.records:
    for response in record.responses:
        if response.status == "submitted":
            # Access evaluation data
            information_quality = response.values["information_quality"]["value"]
            tool_usage = response.values["tool_usage"]["value"]
            response_quality = response.values["response_quality"]["value"]
            # ... process as needed
```

## Customization

You can modify the dataset structure by editing the fields and questions in the `create-evaluation-dataset.js` or `chat_evaluation_python.py` files. After modifying, recreate the dataset to apply your changes.
