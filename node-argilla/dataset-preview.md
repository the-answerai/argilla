# Chat Evaluation Dataset Preview

This document provides a visual representation of how the chat evaluation dataset will appear in Argilla.

## Dataset Structure

### Fields

| Field Name | Description | Type | Required | Markdown |
|------------|-------------|------|----------|----------|
| `user_query` | The question asked by the user | Text | Yes | No |
| `ai_response` | The response generated by the AI | Text | Yes | Yes |
| `agent_reasoning` | The reasoning process of the agent | Text | Yes | Yes |
| `used_tools` | The tools used during the conversation | Text | No | Yes |
| `source_documents` | Documents referenced during the conversation | Text | No | Yes |

### Questions (Evaluation Metrics)

| Question Name | Description | Type | Required | Values |
|---------------|-------------|------|----------|--------|
| `information_quality` | Rate the accuracy and relevance of the information provided | Rating | Yes | 1-5 |
| `tool_usage` | Rate how effectively tools were used to answer the query | Rating | Yes | 1-5 |
| `response_quality` | Rate the overall quality and helpfulness of the response | Rating | Yes | 1-5 |
| `document_relevance` | Rate the relevance of the referenced documents | Rating | No | 1-5 |
| `improvement_feedback` | Provide specific feedback on how this response could be improved | Text | No | - |

### Dataset Metrics View

After evaluating multiple records, Argilla will provide metrics that help you analyze the quality of your AI system. For example:

```
Information Quality (Average): 3.8/5
Tool Usage Effectiveness (Average): 3.2/5
Overall Response Quality (Average): 3.5/5
Document Relevance (Average): 4.1/5
```

These metrics can be filtered by any metadata fields (such as `chat_id`, `created_date`, or `session_id`) to help you analyze performance over time or for specific types of queries.
